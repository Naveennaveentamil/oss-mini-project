EcoTrack

Smart Carbon Footprint Calculator for Sustainable Living

About the Project

EcoTrack is a simple open-source web project that helps users calculate their approximate daily carbon footprint based on travel and electricity usage. The goal is to create awareness about eco-friendly habits.
